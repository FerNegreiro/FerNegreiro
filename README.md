```yaml
nome: Fernando Negreiro
cargo: Analista de BI e Engenheiro de Dados
foco: Power BI | Engenharia de Dados | Cloud
stack: Power BI | SQL | Python | BigQuery | dbt | Airflow | GCP | AWS
```

Trabalho com dados de ponta a ponta: construo pipelines de ingestão e transformação, modelo os dados em camadas analíticas e entrego painéis no **Power BI** que apoiam a tomada de decisão.

Comecei na área de **MIS**, criando dashboards e relatórios de KPIs com SQL, e hoje uso **Python, BigQuery, dbt, Airflow e Docker** para automatizar todo o caminho até o indicador. Também tenho experiência com **governança de dados no GCP aplicada à LGPD** e com desenvolvimento de **APIs em Python**.

## 🚀 Projetos em destaque

### 📊 Engenharia de Dados para E-commerce

**Python · Pandas · PyArrow · Parquet · BigQuery · dbt · Power BI · Pytest**

Projeto de ponta a ponta, da geração dos dados até o dashboard:

- Geração de dados sintéticos e processamento ETL/ELT
- Validação de qualidade dos dados
- Camadas analíticas em Parquet e carga no BigQuery
- Transformações e modelagem com dbt
- Dashboard executivo no Power BI
- Testes automatizados com Pytest

[![Ver projeto](https://img.shields.io/badge/Ver%20projeto-E--commerce%20Data%20Engineering-181717?style=for-the-badge&logo=github)](https://github.com/FerNegreiro/Ecommerce-data-engineering)

<br>

### 🛡️ Portal do Titular: estudo de caso LGPD

**Análise de negócios · Requisitos · BPMN · Python · Flask · BDD**

Portal de autoatendimento para pedidos de titulares da LGPD, da descoberta à entrega:

- Entrevistas, Lean Inception e requisitos com matriz de rastreabilidade
- Processos modelados em BPMN (AS-IS e TO-BE)
- Backlog priorizado com RICE e WSJF e proposta comercial
- MVP com API documentada em OpenAPI, critérios de aceite em BDD e 31 testes automatizados
- Página de demonstração interativa com alertas de prazo e trilha de auditoria

[![Ver projeto](https://img.shields.io/badge/Ver%20projeto-Portal%20do%20Titular-181717?style=for-the-badge&logo=github)](https://github.com/FerNegreiro/portal-do-titular)

<br>

### ☁️ Cloud Data Platform

**FastAPI · PostgreSQL · Docker · Kubernetes · GitHub Actions · Terraform · Prometheus · Grafana**

[![Ver projeto](https://img.shields.io/badge/Ver%20projeto-Cloud%20Data%20Platform-181717?style=for-the-badge&logo=github)](https://github.com/FerNegreiro/cloud-data-platform)
